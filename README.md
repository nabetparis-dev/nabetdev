# NABET PARIS Next.js SSR Outlet - Cart Pro

Version avec ergonomie e-commerce:
- Ajout au panier direct depuis la page d’accueil
- Panier latéral propre
- Quantités + suppression
- Total en direct
- Paiement Stripe sans popup email moche
- Stripe demande email / téléphone / adresse dans Checkout
- SSR SEO conservé

## Installation

```bash
cd ~/Downloads/nabet_paris_next_ssr_outlet_cart_pro
npm install
npm run dev
```

Ouvre:
http://localhost:3000

Admin:
http://localhost:3000/admin

Mot de passe:
nabet123
